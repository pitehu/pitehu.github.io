# Tiancheng Hu website

Published from the root of the main branch through GitHub Pages.
Custom domain: tiancheng.hu.

Edit the biography, research, service, and profile in _source/.
Edit styling in assets/academic.css. Replace the CV in uploads/.
Run npm run build after editing content, then git add -A, git commit, and git push.
Run npm run dev for a preview at http://127.0.0.1:4173.

No dependency installation is needed. Node.js is required for rebuilding.
